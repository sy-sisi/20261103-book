북앤드림 독립출판 페어 웹사이트

구성
- index.html : 행사 메인 안내 페이지
- register.html : 사전등록 / 북토크 예약 / 출판사 참가 신청 시연 페이지
- style.css : 전체 디자인 및 반응형 스타일
- script.js : 팝업, 모바일 메뉴, 신청 폼 인터랙션
- assets/ : 웹페이지에 실제 삽입된 SVG 이미지 파일

실행 방법
1. ZIP 압축을 풉니다.
2. index.html을 브라우저에서 엽니다.
3. 사전등록 버튼은 register.html로 연결됩니다.

수정 팁
- 행사명, 날짜, 장소, 작가 소개는 index.html에서 수정합니다.
- 색상과 레이아웃은 style.css의 :root 변수와 각 클래스를 수정합니다.
- 팝업 및 폼 동작은 script.js에서 수정합니다.

참고
현재 날짜, 장소, 작가, 프로그램, 연락처 등은 시안 제작을 위한 가상 정보입니다.
신청 폼은 화면 시연용이며 서버 전송이나 실제 개인정보 저장 기능은 포함하지 않습니다.
이미지는 외부 URL을 불러오지 않고 assets 폴더의 SVG 파일을 직접 삽입합니다.
